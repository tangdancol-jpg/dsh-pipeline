# shell 边界（主对话的「只读」在 shell 面怎么定义）

> 本文档回答一个问题：**主对话的"只读"是否包括 shell？** 报告里实测：主对话可以
> `Start-Process python -m http.server`、`Remove-Item -Recurse` 删 375 MB、`Invoke-WebRequest` 探活
> —— 这些**全放行**；而它的设计目的是"不读代码正文、不写文件"。
>
> 状态：**已按本口径落地判据**（2026-10-19，`lib/guard/shell.js` 的 `judgeMainShellBoundary`，默认启用，回归 `f41` 52/52）。

## 1. 为什么不能简单地说「主对话不许 shell」

- 主对话是**调度台**：它需要探活（本机服务起没起来）、清理测试残留（`reports/tester/edge-*`）、
  看磁盘/进程这类**环境级**操作 —— 这些不是"干活"，是"保证流水线能跑完"。
- 一律禁 shell 的代价：上面那几件事会被逼进"用户手动做"或"编写席位顺手做"，
  后者恰恰是越权（编写不该碰测试残留/环境）。
- 真正要防的也不是"能不能跑命令"，而是**借 shell 绕开三权分立**：
  读源码正文、写交付根/源码树、把凭证落盘。

## 2. 边界（建议口径）

| 类别 | 主对话 shell | 判据（若落代码） |
|---|---|---|
| **环境级只读/探活** | 允许 | 只读命令（`Get-ChildItem` 清单、`Test-NetConnection`、`Invoke-WebRequest` 探活、`Get-Process`、`tasklist`、`curl` 无副作用 GET）—— 不写盘、不改状态 |
| **清理本单测试残留** | 允许（限定路径） | `Remove-Item` 只允许落在 `<项目根>/.pipeline/<本单>/reports/**` 下，且必须写一行审计（删了什么、多少字节、为什么） |
| **读源码正文** | **禁止**（既有判据已覆盖"读代码正文"） | 既有 shell 判据；不因本条放宽 |
| **写交付根 / 源码树** | **禁止** | `>` / `>>` / `Set-Content` / `New-Item` / `Copy-Item` / `Move-Item` 的目标落在 `change_scope` 或项目源目录 ⇒ 拒 |
| **复制浏览器 profile / 凭证** | **禁止**（P0-2 同时覆盖） | 见 `f24` 那套判据 |
| **起服务/进程** | 允许（环境级），但必须能停 | 报告里 `http.server` 属于此类；建议要求"起服务须记录 PID/端口，收尾清理"（文案要求，不硬拦） |

一句话：**主对话可以动"环境"，不可以动"交付物"与"源码"**。环境级操作留痕；交付面仍走三权分立。

## 3. 为什么不直接落成硬判据（本轮）

- shell 命令的形态太多（`python -c`、管道、脚本文件、PowerShell 编码命令），
  静态判据只能覆盖一部分；把它写成"看起来全禁"的规则，实际给的是**虚假的安全感**。
- 而它真正被滥用的两条路（读源码正文、写交付面）**已有既有判据覆盖**（只是报告里的清理动作恰好
  不属于这两条）。所以本轮先把口径写清楚，落代码放到 P0-2 的路径判据之后，避免两个新判据互相打架。

## 4. 后续落地建议（若用户确认口径）

1. **路径类判据优先**：`Copy-Item` / `Remove-Item` / 重定向目标的路径判定
   （复用 `lib/guard/targets.js` 的目标抽取 + `change_scope` 比对）；
2. **只读命令白名单**：`lib/guard/shell.js` 里给主对话加一份"环境级只读"白名单，其余命令要求说明
   （或直接拒，看误伤率）；
3. **清理必须留痕**：`report/tester/edge-*` 这类删除动作写 `audit.jsonl` 一行
   （`action: shell:cleanup`，路径 + 字节数）——与"绝不静默"同一口径；
4. **不要碰"起服务"**：起进程/端口本身不做静态拦截（否则误伤正常探活），只要求收尾清理。

## 5. 与其它问题的关系

- **P0-2（浏览器 Profile 数据卫生）**：它的路径判据与本设计共用"目标路径"抽取；
  P0-2 先落（更明确、更危险），shell 路径判据可以复用同一份工具。
- **"完全权限"档**：用户显式给 danger-full-access 时，本口径**不豁免**"禁止复制凭证进工作区"
  —— 那是数据卫生，不是权限档问题。
