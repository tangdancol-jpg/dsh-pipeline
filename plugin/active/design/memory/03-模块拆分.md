# 03 · 模块拆分（一文件一职责）

> 规矩来自 `plugin/active/CONVENTIONS.md`：一文件一件事、≤400 行、文件名是**说得出职责的名词短语**、
> **禁止**往既有大文件堆叠（`lib/states.js`、`lib/tiers.js`、`index.js`、`lib/tools.js`、
> `lib/store/precondition.js` 一概不碰 —— 名单见 `CONVENTIONS.md` §5）。
> 本文件只给**落点表**；为什么接在那里在 `04-接线点.md`；设施依据在 `02-DSH-原生设施.md`。

---

## 1. 新域：`lib/memory/`

按 `CONVENTIONS.md` §2 的格式，先把新域的职责边界说清楚：

| 目录 | 负责什么 | **不**负责什么 |
|---|---|---|
| `lib/memory/` | **记忆**：写什么算一条记忆、怎么按相关性取回、活文档长什么样 | 状态迁移表（`lib/states.js`）、闸门（`lib/guard/`）、存储写入的**事务语义**（`lib/store/`）、工具的参数校验（`lib/tools/kit.js`） |

★ 为什么值得单开一个域：它的**改动原因**与既有域都不同 —— 记忆的"
一条记忆长什么样""取回哪几路""活文档多久更新一次"变了才改它，
与状态机、守门、角色权限都无关。按 `CONVENTIONS.md` §3.1 的判据（"改动原因是不是只有一个"），
它够格独立成域。

## 3. 为什么是这三路取回（而不是四路或两路）

判据：**这一路在"一项目几十到几百条记忆"的规模下，能不能真的提高命中率，且不用模型。**

| 路 | 上不上 | 理由 |
|---|---|---|
| **时间** | ✅ 上 | 最便宜、最常用。真实查询形状是"**这个任务**之前怎么处理的""**最近**改过什么" |
| **关键词** | ✅ 上 | 确定性、可解释、可测。记忆文本里天然有任务 id、路径、状态名、错误码 |
| **实体** | ✅ 上 | 这是**付费意愿最高**的一路：`task_id`、`change_scope[].path`、`role`、`seat`、`state`、`handoff_id` 就是现成的主键，"同一事物不同叫法"（`writing/编写/writer`、`T-1/T-20261011-214043`）必须归到一起 |
| **语义 / 向量** | ❌ 不上 | 无 embedding 设施（用户点名不抄）；量级不需要；引进来就多一个模型依赖与一个不可解释的黑盒 |
| 交叉编码器重排 | ❌ 不上 | 用户点名不抄；确定性打分（实体命中 > 关键词命中 > 时间新）已够稳定、且**可测试** |

**"实体图"在本地的形态**：不是图数据库，而是**记忆之间的主键外键关系**（`refs.task_id`、
`refs.paths[]`、`refs.handoff`）＋**一张别名表**。这三样都已经在 `.pipeline/<task>/*.json` 里了。

## 4. 单文件不超限的自检

- 全表最长预计 180 行（`lib/tools/memory.js`），其余 ≤140 行 —— 上限 400 行，**没有一项需要再拆**。
- 若实现时 `lib/tools/memory.js` 因两个工具的 schema 膨胀超 400 行，
  按职责拆成 `lib/tools/memory-recall.js` / `lib/tools/memory-remember.js`
  （**两个工具两件事**，这符合"一文件一职责"，不是为凑数）。
- 每个文件**第一行**必须是"这个文件负责什么"的单行注释（`CONVENTIONS.md` §4）。

## 5. 测试落点（一测试一文件）

命名照 `CONVENTIONS.md` §3.2：`tests/<编号>-<slug>-check.mjs`。
记忆域的编号从 **`m1`** 起（与既有 `p1`–`p8` 不撞号），可直接 `node` 跑。

| 测试文件 | 测什么（一件事） |
|---|---|
| `tests/m1-memory-record-check.mjs` | 一条记忆的规范形状与校验（含拒绝畸形） |
| `tests/m2-memory-alias-check.mjs` | 实体归一（同物多名折叠、异物不折叠） |
| `tests/m3-memory-append-check.mjs` | 追加写：并发追加不互相覆盖、**写失败不影响调用方** |
| `tests/m4-memory-retain-hook-check.mjs` | retain 缝只在**该记**的时候记（非 `pipeline_*` 工具不记） |
| `tests/m5-memory-route-check.mjs` | 三路各自命中正确 + 合并去重 |
| `tests/m6-memory-budget-check.mjs` | **上限是硬的**：超限必须截断，且截断后仍在限内 |
| `tests/m7-memory-live-doc-check.mjs` | 活文档渲染幂等（同输入同输出；重复写不产生差异） |
| `tests/m8-memory-switch-check.mjs` | **总开关关掉 ⇒ 记忆域一条缝都不挂**（对照既有的 `switch-off-no-hooks-check.mjs`） |

★ 按 `CONVENTIONS.md` §6：新测试**默认**要登记进 `tests/run-all.mjs`；
本域若仍处在"零修改既有文件"的批次内，则在 `WIRING.md` 里记一条待登记
（与 `p1`–`p8` 同样的处置），**不许**把"没登记"说成"登记过了"。
