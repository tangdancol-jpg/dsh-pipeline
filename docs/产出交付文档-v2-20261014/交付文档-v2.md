## 0. 三行说清「东西放哪」

1. **每一步的产出 = 一份「交接物」** ⇒ `.pipeline\<单号>\handoffs\NNN-<kind>.json`。这是**唯一**的交付入口（`pipeline_handoff`，`lib/tools.js:2308`）。

**「打回」在代码里 = 一份「方向相反」的交接物 + 一个回退状态事件。** 代码里**没有**一个叫「打回」的独立东西 —— 打回是**两种既有动作的组合**。另有把两者打包的工具：`pipeline_rework { task_id, target, reason }`（`lib/tools.js:2748`，`target` 只能 `writer` / `tester`）。
