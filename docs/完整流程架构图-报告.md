   - 即：**节点文本（tag/sublabel/label）在最小可读字号下放不进盒宽时，渲染器不是给结构化诊断而是直接崩**。判据在 `renderers/workflow/workflow-compiler.mjs:1097`（tag）与 `:2570-2590`（本应报 `Tag … needs ~Npx … increase node.width`），崩溃发生在渲染阶段、早于该校验。
